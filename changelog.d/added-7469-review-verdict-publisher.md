- Added an opt-in reviewer verdict publisher (`review.publish_verdicts`, off by default): the hive posts each current review verdict — findings with their `file:line` citations, the per-perspective breakdown, and the aggregate verdict — as a comment on the PR it judged. The comment is idempotent on the PR's head commit, so a re-review edits the existing comment instead of adding another, and an unchanged verdict performs no GitHub write. The reviewer agent gains no GitHub write access: the comment is written by the spoke using the App token it already holds. (#7469)
