- The `reviewer` agent is now part of the L5 and L6 ACMM packs, on a 30-minute cadence in every governor mode ([#8023](https://github.com/hivecommons/hive/issues/8023)). It was in no pack at all, so an operator at L5 or L6 who wanted repo-grounded PR review had to create the agent by hand from the dashboard — and at exactly the levels where the queue is the bottleneck. L5 holds every agent PR behind a `hold` label and L6 auto-merges on green CI; in both, the reviewer is the agent that makes that queue finishable by a human, because it reads the open PRs, posts a review comment a maintainer can act on, and hands the hive the verdict whose `requires_human` and `reject` values put the triage label on. It joins as `mode: ADVISORY` with `converse: true` — it opens nothing and merges nothing, at either level — running the existing `reviewer-queue.md` policy with a 1h stale timeout above its cadence. L1–L4 are unchanged: the reviewer stays opt-in below L5, and a pack apply still leaves a hand-created one's mode, model, backend, and pause state alone. A hive that already created `reviewer` by hand keeps every field it claimed; the pack fills only what was never set, and an explicit `converse: false` is a revocation that survives every re-apply rather than being re-granted on the next restart.
