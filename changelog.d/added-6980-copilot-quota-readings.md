- Contributor quota readings from GitHub Copilot are now normalized from the documented enhanced billing platform endpoint `GET /users/{username}/settings/billing/premium_request/usage` (kubestellar/hive#6980), the fourth adapter alongside Codex, Claude Code, and Agy. Because that endpoint reports *consumed* premium requests (`grossQuantity` / `discountQuantity` / `netQuantity`) but never the plan allowance, `pct_remaining` cannot be derived from it — so the adapter honestly reports the headroom as `unknown` (a probe error the guard holds on, never a fabricated percentage) while surfacing the consumed count informationally and populating the paid-overage signal from `netQuantity > 0`. Copilot's unit is a count of premium requests per calendar month, so the emitted window carries `kind: monthly` with its duration and a first-of-next-month reset, and is governed by the base reserve (it holds as `guarded_unknown_window`; the short/weekly overrides do not apply). Obtaining a reading is a plain authenticated GET that consumes no model turn and no premium request; a missing token scope, a logged-out CLI, or an unrecognized schema is reported explicitly and enters the unknown-data behaviour rather than a permissive reading. No code path creates, modifies, or mutates a Copilot budget — a test asserts it, per #6833's "no code path purchases credits". A schema-derived fixture ships for the parse path, to be replaced once a real recorded payload is available. (#6980)
